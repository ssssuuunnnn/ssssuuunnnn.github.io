這週分享使用 AI 開發系統(react + python & 二人開發)，最近越用越有心得，
最近也開始對使用 claude design + claude code 可以增加開發效率 10 倍以上有很深的感受，
常常聽到有些人問說 AI 到底對開發上有多少的幫助，現在的我終於可以回答的出來(年初的我還沒辦法回答)。
最近在開發生做到了像下圖的功能，

![圖1](/assets/images/2026-09-06-ai-dev-efficiency/圖1.png)
![圖2](/assets/images/2026-09-06-ai-dev-efficiency/圖2.png)

這個功能就我的感受，在開發上也是一個不小工程，完全人工處理不來個二週以上也要來個一週，
但是經過 AI 的幫助，直接透過與 claude design 的討論及設計，
再使用 claude code 直接進行需求說明及開發，
一來一往一人僅花了一天就完成了(途中還有去做別的事)，
過程中也是經過了多次的修改(有時候功能想的跟結果不一樣，或是畫面上呈現的調整)，
後期也完成程式自動化測試及PRD、API文件上調內容調整，
最後的結果也能完全符合目標。

有這樣的效率屬實是讓我很驚訝，
其他的頁面在規畫、設計及開發上，即使是較簡單的頁面也是分分秒秒的事情，
claude design 在後台介面的設計的想法上，給了我很多很棒的建議，
claude code 不管是環境的建立、資料庫的規劃到程式的實作，效率上遠超過我自己的開發，
在實務上得確是有二位得力(實力遠超我)的助手，協助我來完成我的想法，當然前題是必需跟它「聊的起來」(說故事的能力跟軟體開發的能力在此顯得極度重要)，
這也讓我對碼農的淘汰更有加速的體會，
對於工程師，勢必要往其他方向轉型。

最後這一個月600元實在是花的太值得了。
